# 多平台同款竞品识别插件

在欧洲电商搜索结果页上传一张参考产品图，逐个比对页面上的商品，找出**同款竞品**。

支持：eBay、OTTO、Kaufland / REAL、ManoMano 德国/法国、Leroy Merlin 法国、Cdiscount、bol.com。非 eBay 平台只采集标题、图片、价格和链接，不读取详情页、卖家和运费。

## 这一版做了什么

**图片识别重做。** 旧版本用 32×32 亮度哈希比对，那套算法描述的是"整体明暗分布"，和外形没关系——白底商品图上，商品占画面多少一变，结果就全变了。现在改为：

- **梯度方向直方图**：直接描述轮廓走向。圆的物体边缘方向均匀分布，方的集中在 0°/90°，这才是"看外形"。
- **裁剪归一**：先把商品从白底里框出来再缩放到统一大小。没有这一步，同一件货拍得远一点近一点会被判成两样东西（实测相似度 0.26，加了之后 0.94）。
- **颜色只占 25%**，且只统计非白底像素——同款常有多个配色，颜色不能主导。

**视觉模型改为逐个比对。** 旧版本把参考图和 5-10 张候选图塞进一次请求，模型注意力被稀释；而且只复核本地初筛的前 5/10 名，初筛错了模型根本看不到真正的同款。现在每个商品单独一次请求，只放两张图，按四个维度打分：

| 维度 | 权重 |
|---|---|
 | 产品类型 | 25% |
 | 核心功能 | 25% |
 | 外形轮廓 | 20% |
 | 结构细节 | 15% |
 | 材质观感 | 10% |
 | 成本档次 | 5% |

返回分项分数 + 判断（同款 / 高仿款 / 同功能相似款 / 不相关）+ 理由，可以自己复核，不是一个黑盒数字。
评分先判断产品类型和核心功能，再判断外观结构。例如参考图是三路电动猫追逐玩具，候选即使外壳不同，只要功能方案相近，也会归为同功能相似款而不是不相关。

**改为侧边栏。** 旧版本是 popup，点网页任何地方就会关闭——而且分析正在跑的时候关掉，进度全丢。侧边栏常驻，不受影响。

**其他：** 抓 500px 原图而非 225px 缩略图；单个失败可单独重试不影响整批；支持中途停止且已完成结果可导出；参考图和设置持久保存。

## 安装

1. 打开 Chrome / Edge 扩展管理页（`chrome://extensions`）
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录
4. 如果之前装过旧版本，点一下刷新图标

## 使用

1. 在支持的平台搜索关键词
2. 点扩展图标 → 侧边栏打开
3. 选择参考产品图片
4. 展开「视觉模型设置」填写接口地址、模型、API Key（填一次即可）
5. 点「采集并分析」
6. 完成后「导出 XLSX」

**粗筛强度**决定多少候选送给模型：

| 档位 | 阈值 | 大致送模型数量（60 个商品） |
|---|---|---|
| 严格 | 0.50 | 15-25 |
| 适中（默认） | 0.35 | 25-40 |
| 宽松 | 0.20 | 40-55 |
| 不筛 | — | 全部 |

**如果发现同款被漏掉了，就把粗筛调成「宽松」或「不筛」。** 本地算法只负责省钱，不决定排名——排名由模型定。

## 接口设置

- 官方 OpenAI（`api.openai.com`）→ 接口格式选「自动判断」或「Responses」
- 第三方兼容接口 → 地址填到 `/v1`，格式选「Chat Completions」
- **模型必须支持图片输入**，否则会返回文字但没有真正识别图片

调用次数 = 送给模型的候选数量 ×（1 + 自动重试次数）。自动重试次数可自定义（0-10 次），默认 2 次。最终评分中本地粗筛占 40%，视觉模型占 60%。详情增强只对 eBay 生效，只读取粗筛低于 90% 的候选中最多 8 个；其他平台只做价格优先采集，不读取详情页。采集会自动滚动并合并虚拟列表中的商品，遇到“加载更多”也会继续读取，避免只拿到第一页的一部分。并发数现在支持到 10，可按接口限流情况调整。

## 自检

改动算法后跑一遍确认没弄坏：

```bash
node verify.mjs
```

或者浏览器直接打开 `test.html`（多了 canvas 相关的验证，还能看到测试用的图形）。

两者都包含核心验证：**同一形状不同大小的相似度，必须高于不同形状**。这条如果挂了，说明裁剪归一出了问题。

## 已知限制

- 只采集当前打开的搜索结果页，不自动切换分页；页面内滚动和“加载更多”会自动处理
- 本地粗筛对材质基本无感，对拍摄角度差异很大的同款可能误杀——这是阈值设得宽松、并且提供「不筛」档位的原因
- 视觉模型的判断用于辅助，最终仍需人工确认
- API Key 保存在本机浏览器扩展存储中，由浏览器直接发送到你填写的接口地址
