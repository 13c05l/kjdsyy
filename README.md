# 跨境电商市场调研与上架工作台

Chrome / Edge Manifest V3 扩展，用于采集欧洲电商搜索结果、识别同款竞品、整理市场调研数据，并为后续多平台上架模板工作流提供产品资料和商家规则入口。

## 当前状态

已实现：

- 多页面侧边栏工作台
- 多平台搜索结果采集
- 页面滚动、虚拟列表和“加载更多”采集
- 商品主键去重和重复采集统计
- 本地图片粗筛
- 视觉模型逐商品比对
- 自定义自动重试次数，默认 2 次
- 市场调研结果查看、筛选和 XLSX 导出
- 产品资料导入和本地保存
- 商家规则子页面和本地保存
- 本地 / 视觉模型最终评分按 40% / 60% 合并

当前仍在开发：

- OTTO 上架模板自动生成
- REAL / VK 上架模板自动生成
- CD / LML / But 上架模板自动生成
- SHEIN 上架模板自动生成
- TK 上架模板自动生成
- Terapeak、卖家精灵、Google Trends 数据导入
- AI 标题、关键词和产品描述生成
- 价格、利润率和销售周期分析

当前模板制作页面已提供平台选择、产品资料导入、市场调研结果查看和商家规则配置入口，但还不会直接生成最终官方上传模板。

用于查看当前任务和进入主要工作流程：

1. 市场调研
2. 模板制作

### 市场调研

用于采集当前打开的电商搜索结果页，并进行竞品识别。

主要功能：

- 上传参考产品图片

- 选择粗筛强度
- 设置视觉模型并发数
- 设置自动重试次数
- 选择是否读取 eBay 候选详情
- 采集当前搜索结果页
- 查看识别结果和相似度
- 导出市场调研 XLSX

### 模板制作

用于选择目标平台，并管理模板生成所需的数据：

- 产品资料
- 市场调研结果
- 商家模板规则

### 设置

用于配置：

- 视觉模型接口
- API Key
- 模型名称
- Responses / Chat Completions 接口格式
- 商家规则

### 商家规则

商家规则是设置页面下的独立子页面，当前包含：

- SKU 原前缀和目标前缀
- 套装 SKU 转换规则
- 未匹配 SKU 的处理方式
- 非欧盟最低利润率
- 欧盟最低利润率
- 新品低于竞品均价金额
- 各平台费率
- 各平台尾程运费
- 默认店铺、仓库和运输时间

- 默认分类和品牌
- AI 标题语言和禁用词

- 未确认内容的处理方式

没有确认的费率、运费、分类和品牌默认保持为空，不自动猜测。

## 市场调研采集

### 采集方式

插件会：

1. 读取当前已打开的搜索结果页。
2. 识别页面滚动容器或页面本身。
3. 分段滚动并采集可见窗口。
4. 等待懒加载和虚拟列表更新。
5. 识别并点击页面内的“加载更多”控件。
6. 合并所有窗口中的商品。
7. 返回结果前进行最终去重。

插件不会自动切换下一页分页，也不会自动绕过登录、验证码或二次验证。

### 去重规则

滑动窗口采集时，同一个商品经常会在多个窗口中重复出现。当前使用两层去重：

- eBay 优先使用商品物品编号作为商品主键。
- 其他平台清理常见追踪参数后，使用站点和商品路径作为主键。
- 每个采集窗口合并时去重。
- 所有窗口采集完成后再次去重。

同一商品重复出现时只保留一条记录，并使用后续采集到的非空标题、价格、图片等字段补充已有记录。

结果摘要会显示本次采集过滤的重复商品数量。

### 当前采集字段

通用字段：

- 排名
- 商品标题
- 价格
- 图片链接
- 商品链接
- 搜索关键词

eBay 可能额外提供：

- 运费
- 商品状态
- 卖家

实际字段取决于平台当前页面结构和登录状态。

## 图片和评分

### 本地粗筛

本地粗筛不调用 API，使用商品图片特征：

- 商品区域裁剪
- 图片尺寸归一
- 梯度方向直方图
- 非白底颜色直方图

本地特征权重：

| 特征 | 权重 |
|---|---:|
| 外形梯度 | 75% |
| 颜色 | 25% |

粗筛只用于减少模型调用，不作为最终判断。

粗筛档位：

| 档位 | 阈值 |
|---|---:|
| 严格 | 0.50 |
| 适中 | 0.35 |
| 宽松 | 0.20 |
| 全量 | 不筛选 |

### 视觉模型评分

每个候选商品单独发送一次请求，使用参考图和候选图进行比较。

模型评分维度：

| 维度 | 权重 |
|---|---:|
| 产品类型 | 25% |
| 核心功能 | 25% |
| 外形轮廓 | 20% |
| 结构细节 | 15% |
| 材质观感 | 10% |
| 成本档次 | 5% |

判断结果：

- 同款
- 高仿款
- 同功能相似款
- 不相关

最终综合分：

```text
最终分 = 本地粗筛分 × 40% + 视觉模型分 × 60%
```

标题和关键词只作为辅助判断，不替代图片识别。

eBay 详情增强规则：

- 只对 eBay 生效
- 初筛相似度达到 90% 的候选跳过详情页
- 只读取低于 90% 的候选
- 最多读取 8 个候选详情

## 视觉模型设置

支持：

- OpenAI Responses
- Chat Completions
- 支持图片输入的第三方兼容接口

建议配置：

- 官方 OpenAI 地址：选择自动判断或 Responses
- 第三方兼容接口：填写接口地址并选择 Chat Completions
- 模型必须支持图片输入

自动重试次数支持 `0-10` 次，默认 `2` 次。

并发数支持 `1-10`。并发越高速度越快，但也更容易触发接口限流。

调用次数大致为：

```text
候选数量 ×（1 + 自动重试次数）
```

## 产品资料导入

在“模板制作 → 任务输入 → 产品资料 → 导入”中选择文件。

支持：

- `.xlsx`
- `.csv`
- `.tsv`
- `.json`

导入规则：

- CSV / TSV 第一行作为字段名。
- XLSX 默认读取第一个工作表。
- JSON 支持对象数组。
- JSON 也支持包含 `rows` 数组的对象。
- 产品资料会保存到浏览器本地扩展存储。
- 导入后显示字段数量、数据条数和前 5 条预览。
- 图片字段当前不处理。

建议产品资料至少包含：

- SKU
- 产品名称
- 采购价
- 库存
- 产品尺寸
- 包装尺寸
- 产品重量
- 包装重量
- 变体信息

字段名称当前不强制固定，后续模板生成模块会增加字段映射和待确认提示。

## 市场调研结果查看

在“模板制作 → 任务输入 → 市场调研结果 → 查看”中打开结果页。

支持：

- 查看平台和搜索关键词
- 查看商品标题
- 查看价格
- 查看运费
- 查看店铺
- 查看相似度
- 点击标题打开商品链接
- 按标题、价格、店铺和链接筛选
- 导出 XLSX

市场调研结果会保存到浏览器本地，关闭侧边栏后仍可查看最近一次结果。

## 导出文件

当前“导出 XLSX”用于导出市场调研结果，不是 OTTO、REAL/VK、CD/LML/But、SHEIN 或 TK 的官方上传模板。

市场调研导出内容包括：

- 排名
- 标题
- 价格
- 模型判断
- 综合相似度
- 标题关键词匹配
- 六项模型评分

- 识别说明
- 商品链接
- 图片链接
- 卖家
- 运费
- 商品状态
- 搜索关键词
- 采集时间

## 安装

1. 打开 Chrome 或 Edge 扩展管理页。
2. Chrome 地址为 `chrome://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目根目录。
6. 如果安装过旧版本，点击扩展管理页中的刷新按钮。

项目使用 Manifest V3，不需要构建步骤，也不依赖项目目录中的第三方运行时包。

## 使用流程

### 市场调研

1. 登录目标电商平台。
2. 打开搜索结果页。
3. 打开扩展侧边栏。
4. 进入“市场调研”。
5. 上传参考产品图片，可选填标题和关键词。
6. 配置视觉模型。
7. 点击“采集并分析”。
8. 等待页面采集和识别完成。
9. 在结果页查看或导出 XLSX。

### 产品资料和模板制作准备

1. 进入“模板制作”。
2. 点击“产品资料”右侧的“导入”。
3. 导入产品资料文件。
4. 点击“市场调研结果”右侧的“查看”确认竞品数据。
5. 进入“设置 → 商家规则”填写 SKU、价格和平台固定字段。
6. 选择目标平台。

模板生成模块将在后续版本接入。

## 自检

运行项目自检：

```bash
npm run verify
```

自检覆盖：

- 图片裁剪归一
- 轮廓特征
- 颜色特征
- 粗筛阈值
- eBay 图片地址处理
- API 地址规范化
- 模型返回解析
- 六维评分
- 标题关键词辅助评分
- 本地 / 视觉模型 `40% / 60%` 权重
- 并发池
- 失败处理
- 致命错误中断

浏览器中也可以打开 `test.html` 检查包含 Canvas 的图像路径。

## 隐私和权限

- API Key 保存在浏览器扩展本地存储中。
- API 请求由扩展直接发送到用户填写的接口地址。
- 产品资料、商家规则和市场调研结果保存在浏览器本地扩展存储中。
- 商品图片可能需要用户授予对应站点的访问权限。
- 扩展不会自动绕过验证码或登录验证。
- 使用第三方接口时，请确认对方的隐私和数据处理规则。

## 已知限制

- 当前只采集正在打开的搜索结果页，不自动翻页。
- 平台页面结构变化可能导致部分字段暂时读取不到。
- 非 eBay 平台当前以价格优先采集为主。
- 本地粗筛对材质和大角度拍摄差异不敏感。
- 视觉模型判断仍需要人工复核。
- XLSX 产品资料读取默认使用第一个工作表。
- 当前导出 XLSX 是市场调研表，不是官方上架模板。
- 模板制作、销量趋势和关键词数据导入仍在开发中。
